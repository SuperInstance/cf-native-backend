# Quilt-as-Git Cloudflare Competition Video Narrative

## 2-Sentence Hook
Quilt-as-Git is a distributed, versioned substrate built exclusively for AI agents, turning every data cell, API, logic module, or hardware address into a live, runnable repository that activates when cloned. Unlike Git, which centers code changes as its core versioning unit, Quilt makes the connections between cells the foundational building block of collaborative, agent-first development.

## 60-Second Opening Monologue
Hi everyone—if you’ve ever watched AI agents spin their wheels fighting siloed repos, merge conflicts that spiral into chaos at scale, or struggled to turn static code into active, collaborative runtime for agent teams, today we’re showing you the solution: Quilt-as-Git, built in partnership with Cloudflare.

## 3-Act Structure
Act 1: Lay out the modern agent workflow crisis: siloed static repos, broken cross-team context, and no shared runtime substrate to connect agent workforces, leaving teams stuck in disconnected, non-collaborative tooling that fails at scale.
Act 2: Walk through cloning a pre-built Quilt customer support cockpit cell, spawning two agent workers that fork the repo, edit connected logic and data cells concurrently, complete a semantic merge without conflicts, and rewind a mistaken change to showcase fast, safe rollback.
Act3: Frame Quilt-as-Git as the next evolution of version control, decoupling chips, logic, and frontend code into reusable cell libraries, with built-in observability cockpit and agentic compiler support for edge and cloud deployments, unlocking flow-state collaboration for agent teams.

## Closing Line
Quilt-as-Git: the repository for every agent, session, task, and user—where your code stops being inert and starts living as a collaborative, agent-native runtime.
